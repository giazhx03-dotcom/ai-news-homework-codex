# 筛选与分类口径

规则入口为 `assistant_news/rules.py` 中的 `classify(entry)`。输入来自 RSS，规则采用标题、简介和来源标签。当前没有模型调用，也不访问文章全文。

1. 先去除识别到的写作署名。例如“本文借助 AI 工具撰写”和“This article was written with assistance from AI”。报道 AI 写作产品的标题本身仍可作为主题证据。
2. 在标题和简介中寻找人工智能、大模型、coding agents、OpenAI、DeepSeek 等概念与实体。英文使用 ASCII 字母、数字、下划线边界，允许“AI芯片”等混排。Claude、Gemini、Nvidia 等有歧义或业务广泛的名字需要技术或企业上下文。仅命中“推理加速器”等可能相关的线索时归入待确认。
3. 已判定相关后，用标题判断主要主题，必要时参考简介、RSS 标签。融资、收购、监管、芯片算力和企业治理归“行业与政策”，模型架构、训练和评测归“模型与研究”，产品、API、Agent 和工作流归“产品与工具”。有明确基准评测而标题无行业事件时，优先“模型与研究”。同一篇仅取一个分类。
4. 有相关性、主题信号不足时进入“待确认”；缺少相关性证据则跳过。来源属于 AI 专栏本身不足以收录。规则可能漏收未提及技术的企业动态，也可能将包含多个主题的条目分到次要类别。调整规则后可用指定区间补查 RSS 仍保留的条目。

| 标题或 RSS 简介（示例） | 结果 |
| --- | --- |
| OpenAI 发布大模型评测基准 | 模型与研究 |
| How iFood scales coding agents across 15,000 repositories | 产品与工具 |
| AI写作工具上线 | 产品与工具 |
| AI 加速芯片企业完成融资 | 行业与政策 |
| 关于人工智能的几点观察 | 待确认 |
| 港队赢得足球决赛，本文借助 AI 工具撰写 | 排除 |
| A family has paid a fee again | 排除 |
| Claude Monet exhibition opens at national museum | 排除 |

同一采集日再次读到同源已收录条目，会刷新其 RSS 字段与分类，并保留首次收集时间。先前已归档日期的日报保持历史快照。
